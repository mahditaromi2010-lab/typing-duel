# ⚔️ Typing Duel

بازی آنلاین دو نفره‌ی «نبرد تایپ»: دو بازیکن از دو دستگاه مختلف به‌صورت زنده با هم مسابقه می‌دهند. هر طرف یک شخصیت رزمی (به‌صورت رندوم از بین دو شخصیت) می‌گیرد، جملات/کلمات پشت‌سرهم نمایش داده می‌شود و هر کس سریع‌تر و درست‌تر تایپ کند، ضربه می‌زند و جان حریف کم می‌شود. بازی سیستم شرط‌بندی سکه و ۳ سطح سختی هم دارد.

## ویژگی‌ها

- 🔴🔵 دو شخصیت اورجینال با طراحی گرافیکی سبک بازی‌های فایتینگ سایه‌ای (Crimson Blade و Azure Fist)، با جان و ضرب‌آهنگ متفاوت.
- ⌨️ هر دور یک کلمه/جمله نمایش داده می‌شود؛ اولین نفری که عیناً همان را درست تایپ کند، ضربه می‌زند.
- 💥 چهار الگوی ضربه‌ی متفاوت (مشت سریع، چرخش‌پا، شمشیر، مشت آتشین) که هر بار رندوم انتخاب می‌شود، با افکت‌های تصویری و شماره آسیب.
- 🎚️ سه سطح سختی (آسان / متوسط / سخت) که زمان هر دور و میزان آسیب را تغییر می‌دهد.
- 💰 شرط‌بندی سکه: هر دو بازیکن مقدار مشخصی سکه می‌گذارند (مثلاً ۱۰۰)، برنده کل مجموع (مثلاً ۲۰۰) را می‌برد.
- 🌐 کاملاً آنلاین و realtime با Socket.io — هیچ نصب اضافه‌ای روی کلاینت لازم نیست، فقط مرورگر.
- 🇮🇷 / 🇬🇧 پشتیبانی از کلمات فارسی و انگلیسی.

## اجرای محلی (روی کامپیوتر خودت)

```bash
npm install
npm start
```

سرور روی `http://localhost:3000` بالا می‌آید. این آدرس را در دو تب/دو مرورگر/دو دستگاه مختلف (در همان شبکه، با آی‌پی کامپیوتر به‌جای localhost) باز کن، یک نام کاربری بزن، تنظیمات را انتخاب کن و روی «یافتن حریف» بزن.

## ساختار پروژه

```
typing-duel/
├── server.js          # سرور Express + Socket.io: matchmaking، دورهای بازی، اقتصاد سکه
├── public/
│   ├── index.html      # تمام صفحات بازی (ورود، لابی، VS، آرنا، پایان بازی)
│   ├── style.css        # تم تاریک فایتینگ، انیمیشن‌های ضربه/آسیب
│   ├── characters.js    # طراحی SVG دو شخصیت اورجینال + افکت‌های ضربه
│   ├── game.js          # منطق کلاینت (ارتباط سوکت، تایپ، تایمر، HP)
│   └── wordlists.js     # بانک کلمات/جملات فارسی و انگلیسی برای ۳ سطح سختی
└── data/users.json      # دیتابیس سادهٔ سکه‌ها (خودکار ساخته می‌شود)
```

## نکته مهم درباره‌ی گیت‌هاب و دیپلوی

این بازی چون **آنلاین و realtime** است (نیاز به یک سرور Node.js که همیشه روشن باشد تا دو بازیکن را به هم وصل کند)، صرفاً آپلود کردن فایل‌ها در **GitHub Pages** کافی نیست — GitHub Pages فقط فایل‌های استاتیک (HTML/CSS/JS) را سرو می‌کند و نمی‌تواند سرور Socket.io را اجرا کند.

### برای آپلود کد در GitHub (مخزن کد، بدون اجرا):
```bash
cd typing-duel
git init
git add .
git commit -m "Initial commit: Typing Duel game"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

### برای اینکه بازی واقعاً آنلاین و قابل‌بازی باشد:
کد را در یکی از این سرویس‌های رایگان/ارزان میزبانی Node.js دیپلوی کن (همه‌شان مستقیم از مخزن گیت‌هابت دیپلوی می‌کنند):

- **Render.com** → New Web Service → ریپو گیت‌هاب را وصل کن → Build Command: `npm install` → Start Command: `npm start`
- **Railway.app** → Deploy from GitHub repo (خودش `npm start` را تشخیص می‌دهد)
- **Fly.io** یا **Glitch.com** هم گزینه‌های مناسبی هستند.

بعد از دیپلوی، لینک عمومی که این سرویس‌ها می‌دهند را به هر دو بازیکن بده تا از هر دستگاهی وارد بازی شوند.

## نکات توسعه‌ی بعدی (اختیاری)

- جایگزینی دیتابیس JSON با یک دیتابیس واقعی (مثل SQLite/Postgres) برای سکه‌ها.
- اضافه‌کردن سیستم ورود واقعی (رمز عبور/OAuth) به‌جای نام کاربری ساده.
- اضافه‌کردن شخصیت‌های بیشتر و افکت‌های صوتی.
- اضافه کردن لیدربورد (رتبه‌بندی بازیکنان بر اساس بردها).
